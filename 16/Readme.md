# 📘 第 16 週｜期末成果週

> 本週無新進度課程內容，為期末報告繳交與課程總結週。

---

## 本週安排

1. **期末報告繳交**：企業 AI 導入企劃書。格式、內容架構、繳交期限與評分規準，請見《課程作業與報告格式規範》C 節。
2. **課程總結回顧**：
   - 第一部分（W1–W2）：AI 發展史、素養與治理框架
   - 第二部分（W3–W5）：機器學習基礎、分類與商業決策門檻、分群與顧客關係管理
   - 第三部分（W6–W9）：深度學習、電腦視覺、金融科技應用
   - 第四部分（W10）：自然語言處理與市場輿情
   - 第五部分（W11–W14）：生成式 AI、提示工程、RAG、AI Agent
   - 第六部分（W15）：AI 專案評審與組織變革
3. **優異企劃案分享**（選擇性）：教師可挑選 1–2 份具代表性的期末企劃書，簡要說明其亮點，作為全班參考。
4. **碩士論文方向回饋**：針對各位這學期累積的論文閱覽簡報主題，教師可提供初步建議，協助尚未確定論文方向的同學收斂範圍。

## 提醒事項

- 期末報告請依規範命名（書面企劃書＋簡報檔各一份），上傳至指定雲端資料夾。
- 期末企劃書應整合全學期練習過的工具：第 1 週數位成熟度健檢、第 3 週商業問題轉譯、第 4 週停損決策分析、第 5 週 RFM 行銷方案（如適用）、第 2 週與第 15 週的風險與可行性評審。
- 感謝各位一學期的參與，期待在企劃書中看到各位如何把課堂上的框架，轉化為自己企業真正能用的 AI 導入方案。
