## Part 1｜主題課程：卷積神經網路與電腦視覺應用

### 一、CNN 為什麼特別適合影像資料

一般的全連接神經網路，會把影像攤平成一維向量輸入模型，但這樣做會破壞像素之間的空間關係（左右上下的鄰近資訊）。卷積神經網路（Convolutional Neural Network, CNN）改用矩陣或張量的形式保留影像的原始結構，並透過三種核心元件逐層處理：

| 元件 | 功能 |
|---|---|
| **卷積層（Convolution Layer）** | 用一組「濾鏡（filter）」在影像上滑動運算，擷取邊緣、紋理、顏色變化等局部特徵，濾鏡數量越多，能學到的特徵類型越豐富 |
| **池化層（Pooling Layer）** | 對特徵圖進行降維與壓縮（如最大池化），去除冗餘資料，保留最顯著特徵，同時提升運算效率與對小幅位移的容忍度 |
| **全連接層（Fully Connected Layer）** | 把前面各層擷取到的特徵統整起來，執行最終的分類判斷 |

**逐層特徵抽象化**：第一層卷積層通常偵測邊緣、線條等基礎元素；隨著層數加深，模型逐步把這些基礎元素組合成角落、曲線等中階特徵；到了更深的層，才會組合成物體的整體形狀（例如貓的臉部輪廓）。這種「由簡單到複雜」的逐層學習，正是 CNN 能在影像辨識上超越傳統方法的關鍵。

### 二、CNN 的商業應用場景

CNN 目前已廣泛應用於自動駕駛（辨識行人與交通標誌）與工廠品質控制（分析產品圖像辨識瑕疵，呼應上週的智慧檢驗主題）。在零售與服務業，CNN 的應用更是直接影響顧客體驗：

- **無人零售**：透過攝影機辨識顧客拿取的商品，自動結帳，不需人工掃描
- **人流分析**：分析顧客在店內的動線與停留時間，找出「熱區」與「冷區」，作為商品陳列與人力配置的依據
- **人臉情緒分析**：辨識顧客在特定場景（試用產品、排隊等待）的情緒反應，作為服務流程優化的依據

### 三、個案：臉部情緒分析的技術邏輯

教科書的臉部情緒分析個案，是一個典型的三分類 CNN 應用（辨識 Happy、Sad、Angry 三種情緒），實作流程包含：

1. **資料正規化**：影像像素值原本是 0–255 的整數，除以 255 轉換為 0–1 的浮點數，讓模型訓練更穩定。
2. **類別轉換（One-Hot Encoding）**：把「情緒類別」從整數（0、1、2）轉換成向量形式（如 [1,0,0]），避免模型誤以為類別之間有大小關係。
3. **模型架構**：三組「卷積層 → 池化層 → 丟棄層（Dropout）」堆疊，濾鏡數量逐層從 8 個增加到 32 個，讓模型先學基礎特徵、再學複雜的情緒特徵。丟棄層會隨機忽略部分神經元輸出，降低過擬合風險。
4. **模型評估**：用保留的測試資料計算準確率，確認模型是否具備良好的泛化能力。

**管理意涵**：情緒辨識技術目前的準確率仍有限（真實情緒表達遠比三種標籤複雜），企業導入時應把它定位為「輔助觀察工具」（例如彙整整體顧客情緒趨勢），而不是對單一顧客做出武斷判斷——這也呼應第 2 週談過的「演算法偏誤與可解釋性」風險。

## Part 2｜Vibe Coding 實作演練：臉部情緒辨識與人流動線模擬

### 範例①　用預訓練模型體驗臉部情緒辨識

**題目定義**：不需要自己從零訓練模型，直接呼叫一個公開的預訓練臉部情緒辨識模型，判讀一張人臉照片的情緒，體驗這類技術在服務場景中的實際輸出樣貌。

**給 AI 的提示詞：**
```
請用 Python 的 transformers 套件，幫我做以下事情：
1. 載入一個預訓練的臉部情緒辨識模型（例如 trpakov/vit-face-expression）
2. 讓我可以上傳一張人臉照片（用 Google Colab 的檔案上傳功能）
3. 印出模型判斷的情緒類別（如 happy、sad、angry、neutral 等）
   與對應的信心分數（百分比），由高到低排序
請給我可以在 Google Colab 直接執行的完整程式碼。
```

**預期產出的程式碼骨架：**
```python
!pip install transformers torch --quiet

from transformers import pipeline
from google.colab import files

classifier = pipeline("image-classification", model="trpakov/vit-face-expression")

uploaded = files.upload()
image_path = list(uploaded.keys())[0]

results = classifier(image_path, top_k=5)
for r in results:
    print(f"{r['label']}：{r['score']*100:.1f}%")
```

**延伸練習**：用同一個人不同表情的照片測試幾次，觀察模型對「明顯情緒」（大笑、皺眉）與「模糊情緒」（微笑但眼神平淡）的判斷穩定度有沒有差異。

**管理意涵**：這個練習能讓各位具體感受到情緒辨識技術目前的能力邊界——它對誇張、明確的表情辨識效果較好，對細微或混合情緒則容易誤判，這正是導入這類技術做服務決策時必須謹慎的原因。

### 範例②　用簡單熱區模擬，體驗人流動線分析的邏輯

**題目定義**：不需要真實攝影機資料，用模擬座標資料體驗「顧客動線熱區分析」的基本邏輯——這是無人零售、門市動線優化背後的資料處理方式。

**給 AI 的提示詞：**
```
請用 Python 幫我做以下事情：
1. 模擬產生 500 筆顧客在賣場內的座標資料（x, y 座標，範圍 0-100），
   讓資料集中在幾個「熱區」（例如靠近入口與試用區的位置點更密集）
2. 用 seaborn 的 kdeplot 或 hexbin 畫出熱區圖，直觀呈現顧客停留的密集區域
3. 標示出密度最高的前 3 個區域座標
請給我可以在 Google Colab 直接執行的完整程式碼。
```

**延伸練習**：調整模擬資料的分布，讓某個區域的密度大幅提高，觀察熱區圖如何反映這個變化；並思考——如果你是門市經理，看到某個貨架區幾乎沒有顧客停留，會怎麼調整商品陳列或動線設計？

**管理意涵**：真實的人流分析系統背後，就是用攝影機影像結合物件偵測技術，把「人」轉換成座標點，再套用類似的熱區分析邏輯——理解這個資料處理原理，有助於在評估相關系統時，問出更精準的問題。
