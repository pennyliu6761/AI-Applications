## Part 1｜主題課程：生成式 AI 的八大提示策略

### 一、為什麼提示工程是一門技術也是一門藝術

提示工程（Prompt Engineering）的核心，是如何設計、調整與優化提示詞（prompt），以便有效引導 LLM 產生精準且符合需求的回應。由於 LLM 的輸出高度依賴輸入內容，語句的細微差異可能造成完全不同的答案。要掌握提示工程，需要理解語言的細節、應用的專業背景，以及 AI 的能力與限制——這代表人類不只要懂得問問題，更要學會「如何問」，才能真正把 AI 變成可靠的夥伴。

對企業而言，精準的提示設計能生成報告、行銷文案或財務摘要，降低人力成本並提升效率；提示工程的核心價值，在於**降低試錯成本，提升輸出的可靠性**。

### 二、八大提示策略

| 策略 | 核心做法 | 商業範例 |
|---|---|---|
| **① 說清背景，點明目的** | 清楚交代任務的背景與目標 | 「我們是運動鞋品牌，目標客群是大學生，想在新學期提升線上銷售，請設計三個社群行銷方案」 |
| **② 設定角色，界定身份** | 讓 AI 模擬特定角色，回覆更專業 | 「你是一位專業財務顧問，請根據以下數據提供三項建議」 |
| **③ 附上資料，依據回答** | 提供附件或最新資料，避免 AI 僅依過往知識庫作答 | 「請根據附件市場調查報告，整理出台灣 18-25 歲消費者的三大購物考量」 |
| **④ 先廣後深，循序漸進** | 先問全面性問題，再逐步追問細節 | 先問「電商常見的三種行銷策略」，再追問「會員制行銷的優缺點與國際案例」 |
| **⑤ 提供範本，依式作答** | 給明確範本，輸出更結構化 | 「請製作表格，欄位為公司名稱／主要產品／定價策略／優劣勢，填入三家競品資料」 |
| **⑥ 設定限制，規範輸出** | 加上字數、語氣、格式限制 | 「請撰寫三則廣告文案，每則不超過 20 字，語氣年輕活潑，適合 Instagram」 |
| **⑦ 分段提問，逐步整合** | 把複雜問題拆解成小步驟，最後整合 | 先問品牌現況，再問品牌比較，最後要求整合成完整市場分析報告 |
| **⑧ 探究原因，解析過程** | 要求 AI 說明原因與邏輯，而非只給結論 | 「為什麼會員制度能提升顧客忠誠度？請說明原因並舉三個成功案例」 |

### 三、完整案例：新品行銷企劃的提示詞演練

假設一家運動鞋品牌計畫推出智慧運動鞋，目標吸引大學生族群，希望用 ChatGPT 協助規劃完整行銷專案，逐步運用提示策略：

**步驟一（策略①）**：「我們是一家主打大學生市場的運動鞋品牌，希望在新學期提升線上銷售，請幫我們設計二個社群行銷方案，轉換成社群貼文範例文案。」

**步驟二（策略②）**：「你的角色是一位行銷顧問，請你提出專業建議。」——把 AI 設定為顧問角色，讓輸出更具策略性。

**步驟三（策略③）**：「請參照下面大學生購物行為的市場調查報告，根據資料分析學生的消費偏好。」（附上真實或模擬的調查數據，例如：45% 消費集中於服飾鞋包、70% 透過網路購物、65% 受價格優惠影響）——讓建議緊密連結實際數據，而非憑空生成。

透過這三個步驟的疊加，同一個 AI 工具，能從「給一般性建議」逐步進化到「給有數據佐證、角色專業化的具體方案」——這正是提示工程的價值所在。

## Part 2｜Vibe Coding 實作演練：八大策略實戰與圖片生成提示詞

### 範例①　同一個問題，套用不同策略比較輸出品質

**題目定義**：選定自己企業的一個真實需求，分別用「籠統版」「套用策略版」兩種提示詞詢問同一個 LLM，具體比較輸出品質的差異。

**操作方式（不需寫程式，直接在 ChatGPT / Claude / Gemini 操作）：**

```
第一版（籠統）：
幫我想一個行銷方案。

第二版（套用策略①②⑥）：
我們是一家 [你的產業]，主要客群是 [描述客群]，
你的角色是一位資深行銷顧問，
請針對 [具體目標，例如「提升會員回購率」] 提出三個行銷方案，
每個方案用不超過 50 字說明，並標注預期成本等級（低／中／高）。
```

**延伸練習**：把第二版提示詞中的策略拿掉一項（例如拿掉角色設定），觀察輸出品質下降的程度，藉此體會每個策略各自帶來的實際差異。

### 範例②　AI 圖片生成的提示詞設計

**題目定義**：練習用結構化的文字描述，生成符合商業需求的視覺素材（例如產品宣傳圖、社群貼文配圖），體驗「用文字精準描述畫面」的提示技巧。

**提示詞設計要點：**
- 主體描述：要生成什麼物件／場景
- 風格描述：寫實、插畫、極簡、復古等
- 構圖與氛圍：色調、光線、視角
- 用途限制：長寬比例、是否需要留白給文字

**給 AI 圖片生成工具的提示詞範例：**
```
一雙白色運動鞋放在木質桌面上，旁邊點綴綠色植物，
自然光從左側灑入，極簡風格產品攝影，背景略微模糊，
整體色調溫暖，畫面右側留白以便加上文案，長寬比 1:1，適合 Instagram 貼文。
```

**延伸練習**：拿掉「長寬比 1:1」「畫面右側留白」這類限制條件，重新生成，比較輸出圖片在「能不能直接商用」上的差異——這說明圖片生成的提示工程，跟文字生成一樣需要「設定限制，規範輸出」的策略。

## Part 3｜提示工程實戰工作坊

**目標**：針對自己企業的一項真實需求（行銷文案、內部報告、客服回覆範本皆可），完整走一次八大策略的組合應用。

**操作步驟：**
1. 選定需求與目標受眾。
2. 依序套用「說清背景」「設定角色」「附上資料」三個策略，撰寫提示詞。
3. 檢視輸出結果，用「設定限制」策略進行第二輪修正。
4. 記錄修正前後的輸出差異。

```
【提示工程實戰記錄表】
需求與目標受眾：___________
第一版提示詞（套用策略①②③）：___________
第一版輸出摘要：___________
第二版提示詞（加入策略⑥限制）：___________
第二版輸出摘要與改善之處：___________
```
